Overview

About Arrow Rush

Arrow Rush is a puzzle and casual game built around arrow escape puzzles. Your task is to work out the correct paths and clear the board, using logical thinking and smart decisions rather than speed or luck.

Gameplay

Puzzle Gameplay Overview

Arrow Escape Puzzles

Challenging puzzles built around arrows that need to escape.

Discover the Correct Paths

Study the board and find which paths lead to a solution.

Clear the Board

Each puzzle is solved by clearing the board.

Logic & Smart Decisions

Progress comes from logical thinking and well-judged choices.
